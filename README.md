The rooms I write up tend to cluster around the work I'm targeting:

How These Are Written

Each writeup follows a consistent structure so they're easy to read and reuse:

Overview — the scenario and objective
Tools Used — what I reached for and why
Investigation — the work, broken into phases
Indicators of Compromise (IOCs) — the reusable output of the analysis
Conclusion — the verdict and the evidence behind it
Defensive Takeaways — how the attack could be caught or prevented

The goal is to document methodology, so each writeup demonstrates process and reasoning rather than just listing answers.
