## Focus Areas

The rooms I write up tend to cluster around the work I'm targeting:

- **Security Operations (SOC)** — alert triage, log analysis, phishing investigation
- **Digital Forensics & Incident Response (DFIR)** — artifact extraction, malware triage, evidence handling
- **Network & Traffic Analysis** — packet inspection, IDS rules, protocol analysis
- **Email & Threat Analysis** — header forensics, SPF/DMARC verification, IOC extraction

---

## How These Are Written

Each writeup follows a consistent structure so they're easy to read and reuse:

1. **Overview** — the scenario and objective
2. **Tools Used** — what I reached for and why
3. **Investigation** — the work, broken into phases
4. **Indicators of Compromise (IOCs)** — the reusable output of the analysis
5. **Conclusion** — the verdict and the evidence behind it
6. **Defensive Takeaways** — how the attack could be caught or prevented

The goal is to document *methodology*, so each writeup demonstrates process and reasoning rather than just listing answers.
